Handout: the BSZ code in this course

Every line of real Python in this course comes from one reproduction: the BSZ step of fhoces/opa-prop40, folder bsz-analysis/py/. BSZ is a paper on the wealth and taxes of California billionaires. Its reproduction has two steps. Step 1 runs shared .sql files over the raw data (daily Forbes snapshots, SEC filings), from Python and from R, and checks that the two exports agree. Step 2 takes the paper's public workbook to every number the R pipeline exports, with a Python twin written to be compared against the R side function by function.

This page lists where that code appears in the course, module by module and then file by file. In modules 1 to 5 the excerpts are condensed to a few lines, the economics is left out, and each slide shows one idiom next to its R twin. Module 7 works on the files themselves, with drills graded by check.py on a synthetic panel in the same shape as the real data (the real data are confidential).

Reading order

The short path through the BSZ code is the "In the wild" slide of each module in order, 1 to 5, then module 7. Each of the five slides is one idiom and takes a few minutes; module 7 is the full set of files with the drills. The SQL course's module 6 covers what the two queries compute, and pairs with module 7 here.
